# First public beta — release draft

Record Cabinet is an album-first listening room: browse sleeves in physical-style bins, use paper dividers to move through a collection, and play records on an integrated turntable.

## Public demo

- No Spotify account required.
- 60 fictional sleeves with 15 original synthesized audio sketches reused across the catalog.
- Touch, mouse, and keyboard browsing; paper dividers and whole-album turntable controls.
- Local problem reports with app version and optional diagnostics.

## Invited Spotify beta

- Saved-album, playlist, Liked Songs, and account-data-file imports.
- Resumable imports and duplicate suppression.
- Local persistence, backups, custom organization, and account-scoped synchronization.
- Automatic genre enrichment with manual corrections.

## Known boundaries

Spotify account authorization and quota limits constrain live testing. The public demo does not stream Spotify audio. Native media controls and background playback still require physical-device testing. Automatic genres can be incomplete or incorrect. Expanded demo sleeves reuse audio and visual motifs deliberately.

This is a draft for the first GitHub release, not a claim that a repository or release tag has been published.
